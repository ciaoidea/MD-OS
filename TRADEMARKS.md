# MD-OS Project Names and Marks

## Scope

The GNU General Public License governs copyright permissions for covered
software and documentation. It does not grant permission to use project names,
logos, or other source identifiers in a way that falsely implies endorsement
or official status.

The following identifiers are used by the official project:

- MD-OS
- MD-OS (Artificial Prefrontal Cortex)
- MD-OS APFC
- the project logo and banner

This policy does not claim that any identifier is registered in any
jurisdiction. Do not use the registered-trademark symbol unless an applicable
registration exists.

## Permitted descriptive use

Truthful, non-confusing references are welcome, including:

- “runs on MD-OS”;
- “compatible with MD-OS”;
- “derived from MD-OS”;
- “a fork of MD-OS”;
- accurate discussion, review, research, teaching, and citation;
- redistribution of an unmodified official package with its original name and
  notices.

These uses must not suggest sponsorship, certification, maintainer approval, or
official release status when none exists.

## Modified distributions

A materially modified distribution should use a distinct primary name and
state its relationship to MD-OS accurately. It may describe itself as a fork
of, derived from, or compatible with MD-OS, provided that the presentation is
not likely to be confused with the official project.

This file does not add copyright restrictions to GPL-covered code, prohibit
forking, or narrow the permissions granted by GPL-2.0-only. It addresses only
truthful project identification and avoidance of confusing source or
endorsement claims. Applicable trademark rights and exceptions vary by
jurisdiction.
