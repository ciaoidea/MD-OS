# Global Runtime Index

The runtime index is the canonical cross-project map of the system.

It should expose:
- core builders
- active projects
- source channels
- compiled natural-language programs
- active work-item summary
- generated Markdown graph status
- generated semantic knowledge graph compact status
- generated semantic-operational runtime compiler status
- self-release index status
- terminal archive counts
- host-local hardware discovery state from `md-os/ops/local/hardware/`
- host-local software discovery state from `md-os/ops/local/software/`
- service state
- root runtime files
